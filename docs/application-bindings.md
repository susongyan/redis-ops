# 应用与集群关联管理

已实现多对多双向维护，复用现有 application_binding 表和绑定/解绑 API，无数据库迁移。

- 业务应用列表点击“管理关联集群”，可多选新增，查看全部已关联集群并逐项解绑。
- Redis 集群点击名称打开详情，在“管理关联应用”中多选新增应用，查看名称、编码、负责人并解绑。
- 新增集群表单支持可选、多选关联业务应用。先创建集群，再逐项绑定，客户端信息留空；部分绑定失败时保留已创建的集群和成功关系，提示从详情补充关联，不重新创建集群。应用列表加载失败不阻塞单独创建集群。
- 已关联选项禁用；提交前重新读取关联，跳过已存在关系，不用空配置覆盖原关系。
- 新增逐项保存，不是批量事务；部分失败保留成功项并只选中失败项供重试。
- 客户端类型、版本和连接池 JSON 用于本次全部新增关联。解绑须确认，只删除关系，不删除资产或 Redis 数据。
- 集群选项分页读取，最多 10000 项，超过时明确报错而非静默只展示第一页。

关联属于人工维护的资产使用关系，不表示实际连接发现、用户访问权限或 Key 归属。
