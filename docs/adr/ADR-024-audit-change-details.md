# ADR-024 审计变更详情

状态：已实现。

保持已有审计动作范围，Platform 在原业务事务内追加不可变的 details_json，
结构为 summary、changes（field/before/after）、reason。只选择明确允许的配置字段，
不序列化整个请求或实体。历史记录保持 NULL，不从当前资源反推历史。

首批补充命令配置、集群基础配置、应用配置与绑定、同步控制及限速、用户角色和状态。
Redis Key/value、密码、密文、密钥、连接串、命令参数 literal、连接池配置和同步过滤规则
均不写入详情。参数结构只记录是否变更；不记录其自由文本。详情大小限制 32 KiB，
单字段文本最多 512 字符并明确标注省略。写入失败使原业务事务失败，不异步丢弃。

新增 V33，仅扩展 audit_log；不修改历史 migration。API 增加 detailsJson，页面提供摘要及
详情对比；未补充的动作继续展示原有基础记录。升级后需重新生成 latest 初始化包。
