# ADR-028：同步任务与主备关系的 IDC 校验边界

- 状态：已接受
- 日期：2026-09-23

## 背景

普通同步创建复用了主备关系的跨 IDC 校验，阻止了同机房迁移、业务拆分和未配置 IDC 的临时同步。

## 决策

将校验分为基础源目标校验和容灾位置校验。无 relationId 的任务只应用基础校验；
有 relationId 的任务，以及主备关系创建、更新，继续要求 IDC 非空且不同。
关联关系的任务创建时重新检查当前资产 IDC，而非只信任历史关系。
同步用途字段不替代关系绑定；不能借此获得未绑定关系的受控主备切换能力。

## 安全与迁移

不同源目标、ACTIVE 状态、版本方向、DB、命令策略及执行预检规则不变。
不改变 Worker 数据面、租约或 fencing，不修改 API 或数据库结构，无数据迁移。
回滚旧版本后，同 IDC 的新任务创建将再次被拒绝。

## 验证

覆盖同 IDC、缺失 IDC、跨 IDC、同集群、非 ACTIVE 集群及绑定关系后资产位置变化的任务创建。
