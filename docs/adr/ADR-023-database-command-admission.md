# ADR-023 数据库命令准入与通用执行

状态：已实现。

Redis Console 不再维护代码级命令名称白名单或黑名单。`operation_command_definition` 是唯一业务准入源；运维维护启用状态、参数结构、风险、审批策略与路由，承担配置正确性责任。Redis ACL 是服务器最终授权边界，平台不自动扩大 Redis 账号权限。

执行器使用 Lettuce RESP2 通用 dispatch，支持标量和有界嵌套数组响应，不再逐个实现命令。仍限制连接时间、命令时间、响应字节、响应元素、嵌套层数及请求参数容量，这些限制与命令名称无关。超时/断线可能已在 Redis 生效，不能自动重试或声称已经撤销。

首期支持结构化单 Key 路由及无 Key 命令（仅 Standalone/Sentinel）。Cluster 无 Key 命令因无法确定目标节点明确拒绝；多 Key 路由、持续订阅和跨请求事务会话不属于本执行模型。单次请求结束即关闭连接。

新增命令默认禁用。普通运维角色和管理员均可维护目录，与现有平台角色边界一致。配置变更要求幂等键、乐观锁和审计。待执行请求保存命令定义 ID/版本；执行时重新验证启用状态、定义版本、参数与审批，配置变化后要求重新创建请求。只保留一个同名定义，旧多版本已存在时不允许新增同名条目。

不预置更多危险命令，不对真实 Redis 执行破坏性演示。原有名称 switch 删除，后台同步与治理专用命令策略不受影响。
