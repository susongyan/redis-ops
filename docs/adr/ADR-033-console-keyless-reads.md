# ADR-033：Cluster 无 Key 只读命令自动路由

状态：Accepted。补充 ADR-032。

数据库显式配置为 READ、NO_KEY 的命令可在 Cluster DB 0 执行，权限仍由数据库目录决定，不探测命令版本、不新增命令名称白名单。分类标注的正确性由维护目录的运维负责。

Platform 从本次连接发现的拓扑中选择一个连接正常、无失败标记的主节点，定向发送一次，不广播、不自动重试。结果带执行节点，节点级结果不声称集群汇总。修改及管理类无 Key 命令仍拒绝。

结果 JSON 增加可空 executionNode；历史 JSON 和构造器兼容，不变更表结构。协议、响应容量、超时、执行认领及未知结果保护不变。Worker 无变化。
