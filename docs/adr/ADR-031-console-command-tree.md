# ADR-031 Console 命令树与逐次确认

状态：Accepted，分阶段实施。扩展 ADR-023；未交付能力不自动开放。

## 决策

Platform 操作领域管理 CATEGORY、FAMILY、COMMAND、SUBCOMMAND、WILDCARD 五类节点。分类仅组织及提供默认策略，命令族仅提供子命令容器，业务准入来自数据库。无需 Redis COMMAND 探测及版本兼容表。

精确子命令优先于显式通配。具体规则禁用、参数错误或权限不足不可回退通配。祖先禁用禁用整个分支。新增节点默认禁用。通配按管理及高风险处理，不能继承普通查询直接执行。

采用逐次确认，不引入写模式、短期授权表和新审批流程。普通查询可直接执行，修改至少确认，高危必须强化确认。用户权限、参数、协议能力和路由检查独立于策略；确认绑定目标、参数摘要与整条策略路径版本。历史 APPROVAL 不可静默变成 DIRECT，应转换为强化确认并使待执行记录失效。

配置属于 Platform MySQL，Sync Worker 和同步契约不变。父子关系、环及同名冲突由后端验证；目录写入串行化，节点乐观锁保留。新迁移仅追加，旧定义保持显式策略，旧待执行操作不自动重放。

## 分阶段落地及失败边界

先落地目录模型、准入引擎及测试，再接入逐次确认、执行认领及 CLI。阶段一不得对外宣称 CLI 和新版高危确认已完成，未接好强化确认的操作必须拒绝而非降级执行。

数据库与 Redis 无分布式事务。后续执行改造必须在发送前持久认领，结果不确定不可自动重放；不得以数据库事务回滚代表 Redis 未执行。响应仅供授权会话查看，日志及审计不保存原始 Key/value、秘密或脚本正文。

无目标兼容检查不等于无执行能力检查：长连接会话、跨 Slot 拆分、未经支持的脚本及广播写入不通过目录配置自行获得支持。
