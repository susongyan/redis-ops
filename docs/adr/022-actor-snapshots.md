# ADR-022 操作身份快照

保留原有 `user:<id>` 稳定主体作为认证与幂等标识。新增可空 JSON 快照列，记录动作发生时的 userId、login、displayName；仅由后端从用户库读取，不接受客户端身份字段。

覆盖审计、同步事件、切换发起人、Console 发起人与审批人、告警确认人及命令策略修改人。Console 实际执行者另行记录，不覆盖发起人。后台系统主体不冒充登录用户。

快照与对应业务写入同条 SQL 保存，读取不查询当前用户覆盖历史。历史行保留 NULL，页面回退原始主体。改名后已有记录不变；幂等命名空间不变。身份读取失败则停止该记录写入。

通过 V32 增量升级，不修改旧 migration；旧 Worker 写入同步事件仍兼容可空列。无需删除历史数据。账号和显示名仅用于受认证的业务页面，不作为指标标签。
