# ADR-029：运维集群详情直接显示 Redis 密码

- 状态：已接受
- 日期：2026-09-23

## 决策

按产品所有者要求，已登录运维用户在集群详情直接查看 Redis 密码。
不增加单独查看按钮、查看审计或展示倒计时。这是原 write-only 凭据边界的明确例外。

GET /api/v1/clusters/{id} 增加 password 字段，无密码时为 null 或省略。
沿用登录鉴权，前后端禁止缓存详情。列表不返回密码，详情对象 toString 脱敏；
日志、审计、指标、幂等存储仍不得包含密码。代理/APM 不得记录详情响应体。
后端通过 RedisConnectionProfileProvider 解密并清理临时字符数组，数据库仍保存 AES-GCM 密文。
关闭详情后清除页面状态，不写 LocalStorage；编辑框留空仍表示保留，测试连接复用后端凭据，
不把详情中的旧密码自动提交为新密码。

## 风险与部署

有权访问详情的登录用户可读取密码，不提供查看追踪，无法撤回已披露明文。
浏览器和 JVM 字符串无法保证立即物理清零。生产应使用 HTTPS，HTTP 不保护传输中的密码。
不开放主密钥、密文或 Webhook 凭据。无需改表，更新前后端生效；回滚移除字段与展示即可。
