# ADR-015：按请求触发的同步辅助分析交付

状态：已接受。

分析属于独立分析领域，接收资产/同步/校验/风险/告警的非秘密观测摘要，返回人工参考建议。
沿用 ADR-012 的“建议不执行”边界；本轮交付 V27 注册资料和 V28 结果持久化，不引入跨领域写操作。

API 通过现有幂等端口提交同步分析，外部 Provider 失败直接报错，不隐式降级，持久化失败不能当作 Provider 失败吞掉。
结果不可变，建议一律要求人工确认。有限响应、字段长度和超时约束限制外部返回，不把任意模型文本当成执行命令。
分析 API 始终可用，不设置启用开关；HTTP/ACP 按 endpoint 和类型选择，仅请求时调用，模拟器不自动注册；配置中心存储安全由外部负责，未接入时仍使用 Spring 外部配置。

注册表当前只承担资料管理，不驱动运行时路由，界面和文档明确说明。动态启停、认证、A2A、自动分析及标准 ACP
兼容性不在本次完成范围；后续启用这些能力需另行设计/验证。这样不将尚未实现的功能当作生产能力发布。

数据库按 V26 基线继续执行 V27/V28，不覆盖已发布 V26 快照或历史 migration。升级前备份，旧代码回滚前检查新增表兼容性。
验证包含输入/响应约束、幂等重放、无开关接口注册、外部失败直报、保存失败边界以及隔离数据库升级。
