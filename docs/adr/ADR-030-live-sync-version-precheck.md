# ADR-030：同步预检以实时 Redis 版本为准

- 状态：已接受
- 日期：2026-09-23

## 决策

资产 Redis 版本为可选展示信息，不作为同步任务创建的准入依据。
Worker 的 VERSION_COMPATIBILITY 通过实际数据连接执行 INFO server 读取 redis_version，
并通过 INFO replication 确认该节点仍是主节点。Standalone 使用配置的数据端点，
Sentinel 解析当前主节点，Cluster 通过 CLUSTER SLOTS 去重后检查所有主节点。

不回写资产版本。不放宽既有版本允许范围、命令策略范围、禁止降级方向和主备 major.minor 相同要求。
混合版本逐节点校验，普通同步要求所有源目标组合都不降级；容灾要求所有节点 major.minor 相同。
错误明确包含源/目标与节点，连接、权限、无版本、格式错误或角色变化均失败关闭，不回退资产值。

## 边界

复用 Worker 凭据及连接解析；预检只读，无 Redis 数据写入。各网络调用使用有限连接和读取超时，
逐节点关闭连接，不把密码或完整 INFO 放入报告。预检不是拓扑锁；完成后的拓扑/版本变化仍需
重新预检，已有运行期命令策略检查保留，不宣称覆盖所有升级或故障切换竞态。
不修改 schema 和 API 结构，更新 Worker 后生效；Platform 创建阶段移除过时资产版本拦截。
