# ADR-032：Console 手动分组与独立命令策略

状态：Accepted，已实现。替代 ADR-031 的父节点授权、策略继承和管理员专属启用限制。

分组仅用于展示，手动新增、重命名和删除，不参与授权。完整命令名称独立维护，子命令无需命令族父节点。每条命令必须配置显式策略；管理员和运维均可创建并启用、修改、禁用及删除。

复用 Platform 命令目录存储，CATEGORY 行仅作为手动分组，parent_id 仅关联分组。参数 JSON 保持内部存储；前端参数表隐藏子命令固定字面量并自动编码。现有协议、容量、单 Key 路由限制不扩大，不新增 Cluster 无 Key 路由能力。

V35 保留命令、操作和审计历史，增加软删除字段。旧继承策略及不可直接转换的通配策略保守禁用并改为显式高危确认，运维重新确认后可启用；旧禁用祖先不能因扁平化使命令被意外启用。命令族退役，精确子命令保留。分组删除时成员转为未分组，不删除命令。

配置写入沿用目录锁、版本和幂等键，删除记录操作人、原因及时间；执行前重新解析目录，删除或变更命令使旧确认请求失效，已发送 Redis 的操作不撤回。Worker 和 sync-contract 无改动。
