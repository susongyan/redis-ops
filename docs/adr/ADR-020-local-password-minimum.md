# ADR-020：本地密码最短六个字符

- 状态：Accepted
- 日期：2026-09-14
- 替代 ADR-019 的密码长度下限，其余认证及授权边界不变。

按用户确认，本地密码最短六个 Unicode 字符，不要求大小写、数字或符号组合，仍允许更长密码。
BCrypt 的 72 UTF-8 字节上限保留，不静默截断。拒绝非法 Unicode 编码。
创建、初始化、修改、重置和本地密码校验共用该策略，已有长密码不变，不重置任何现有凭据。

较短密码降低了猜测成本；保留 BCrypt、登录失败限速、会话校验和首次改密。
企业认证仍只是扩展预留，不能宣称企业认证目前已经保护本地账户。
