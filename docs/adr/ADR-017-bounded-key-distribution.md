# ADR-017：有界 Key 前缀分布分析

状态：Accepted。日期：2026-09-14。实现和验证范围见 [运行手册](../key-distribution.md)。

Platform 分布分析领域拥有只读扫描任务、按集群互斥的运行槽及有界聚合结果，不依赖 Sync Worker。
只统计 SCAN 观测次数，不读取 value，不作全量去重或一致性快照承诺。
固定规则采用有上限的分组表；Top-K 使用 Space-Saving 并报告估计上下界。
原始样本集合仅在受限接收缓冲和五分钟浏览器预览中存在，不进日志、审计、指标、数据库或异步 payload。
聚合标签可能因用户取段规则恰好等于某个 Key；页面预览用于识别这种高基数/隐私风险，不提供逐 Key 明细存储。
仅允许有界 RESP 接收路径；SCAN COUNT 不是响应大小保证。超限页不能提交任何部分统计或游标。
游标和聚合状态在同一事务内校验 owner、generation 和有效租约后提交；旧执行者不能覆盖新执行者。
按集群互斥涵盖预览和任务；每进程默认一项、最多两项，不在进程内排队。
拓扑变化结束为不完整，暂停保留最后提交状态，恢复重新核对拓扑。所有改动不执行 Redis 业务写命令。
新增迁移与最新完整 SQL 同步交付；历史 migration 保持不可变。

## 数据与失败边界

任务状态为 QUEUED、RUNNING、PAUSED、COMPLETED、INCOMPLETE、FAILED、CANCELLED。
只有目标分片全部游标归零且最终拓扑核对通过才允许 COMPLETED；预算终止不冒充完整遍历。
数据库事务是本分析的统计事实，不改变同步领域中目标 Redis checkpoint/fence 的事实优先级。
运行表保存集群互斥资格；游标与聚合 checkpoint 放在任务表，避免执行槽复用丢失暂停任务状态。
每次接管递增 generation；所有结果写入在有效租约检查和行锁保护下事务提交。

## 取舍与迁移

不新增运行服务或公共契约模块；复用资产连接配置端口，但不复用无接收大小上限的整页客户端接口。
选择有界近似统计而不是 Redis Key 明细外存或全量去重，因此内存和存储只随固定预算增长。
每批新建当前分片连接简化取消与资源释放，但增加连接/认证成本；生产需按自身 RTT 收紧速率。
V30 为纯新增表，先迁移再部署 API/前端。应用回退保留新表；不自动删除分析结果或修改业务 Redis。
