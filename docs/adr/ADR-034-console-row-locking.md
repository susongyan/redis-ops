# ADR-034：命令目录按行协调

状态：Accepted。替代 ADR-032 的全局目录锁。

命令配置低频修改，使用既有 version 乐观锁及名称唯一索引处理冲突，不再通过独立表串行化整个目录或 Console 请求。事务失败交给调用方刷新重试，不自动覆盖。

关联分组前通过 SELECT FOR UPDATE 读取未删除 CATEGORY 的当前名称，锁仅覆盖目标分组。分组修改/删除自身的 UPDATE 获取同一行锁；删除和成员解绑在同一事务完成。这样删除先完成时新增关联失败，新增关联先完成时删除会将其转为未分组。分组重命名与关联创建亦一致。命令执行仍重新校验定义指纹，执行记录通过 version 抢占，不保证撤回已领取或发送的 Redis 命令。

V36 删除只有协调用途、无业务记录的 operation_catalog_lock；不修改历史 V34/V35。升级须停止旧 Platform 实例，再部署新版本。无需新增 version 字段，Worker 不受影响。目录容量检查不再是跨请求严格互斥额度。
