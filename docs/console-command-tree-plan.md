## 目标与边界

Console 面向运维，提供 CLI 风格输入、节点诊断和受控数据修改。命令树同时提供页面提示与后台准入规则。不读取 Redis COMMAND 元信息，不维护 Redis 版本兼容矩阵；平台校验授权、策略、参数与路由后发送命令，由 Redis 判断命令及参数是否支持。

本次属于 Platform 操作领域及前端，不改变 Sync Worker、同步命令策略或治理任务。单次命令不是持久终端会话；订阅、阻塞会话、跨请求事务和 Lua 执行不在首期范围。能力未实现时，即使目录配置允许，也不得执行。

## 命令树与策略

- 分类节点仅组织目录；命令容器组织子命令；可执行节点保存明确的操作属性、参数规则、路由、风险和帮助信息。
- 执行方式为直接、写模式、单次确认、审批或禁止；属性与权限独立检查，不因继承直接执行策略而获得写权限。
- 执行方式可继承最近显式配置；属性、参数及路由不可依靠分类猜测。
- 禁用父节点禁用整个子树；新节点默认禁用。策略修改及节点移动展示受影响命令，保存版本和审计。
- 命令关键字大小写归一化，参数字节语义不随之改变；未知命令默认拒绝。
- 参数能够改变读写行为时必须限定允许选项；无法可靠区分时要求更高权限或拒绝，不按查询放行。

### 子命令与显式通配

仅配置 CLUSTER 容器不会授权子命令。CLUSTER INFO 等精确规则独立授权。CLUSTER * 是显式的整族授权规则，不是展示目录的隐含含义。

匹配顺序：祖先启停检查 → 精确子命令 → 显式通配 → 默认拒绝。

精确规则存在时，无论禁用、参数不匹配、权限不足或审批未完成，均不能回退通配。相同匹配标识必须唯一。父容器不允许同时成为不受约束的通用执行入口。

通配只能由管理员或显式授予策略管理权限的人启用，按管理能力处理，不作为普通查询、批量节点查询或普通写模式的放行入口。必须显式配置确认方式和路由。未知子命令不得猜测 Key 位置、自动跨 Slot 拆分或广播；只能在支持的单次执行模型内执行，必要时指定已验证属于资产的节点。不支持的协议行为不因通配而开放。

## 权限与变更

管理员和运维均可查看命令树、编辑说明/示例及提出执行定义变更。新增、放宽或改变属性、路由、参数等会影响准入的修改形成待审核版本，由管理员或策略管理权限持有人批准后原子生效，不修改当前生效定义。运维可直接禁用或收紧；无法证明是收紧的变更按扩大权限审核。审批不可自行批准。

Console 查询、修改、管理和策略管理为独立能力。普通修改可使用绑定用户、集群、DB 的短期写授权，默认 15 分钟；各实例共享记录，每条执行检查过期、撤销和当前权限。高危确认绑定目标、规范化参数摘要及生效策略版本，不被写模式豁免。

## CLI 页面

- 目标栏始终显示集群、环境、DB、节点模式和写授权状态。
- 命令树可收起，同一份生效定义生成补全、固定选项、语法与示例。
- Enter 单条执行，Shift+Enter 编辑换行；粘贴多行不自动批量执行。明确引号/转义规则，不经过 Shell。
- 上下键浏览当前页面历史；不自动扫描真实 Key 做补全，不写 LocalStorage。
- 结果显示类型、节点、耗时和限制状态；多节点结果分块显示。清屏不删除审计，停止等待不表示 Redis 操作被撤销。
- 查询直接执行；写模式和高危确认使用清晰 Web 控件。窄屏保留目标、权限及帮助入口。

## 路由与失败边界

支持已定义 Key 的自动路由、指定节点，以及显式标注允许的全部主节点诊断查询。节点由后端资产拓扑解析，不允许任意外部地址。写入前复查角色；Sentinel 默认解析数据主节点。全主查询限制扇出并发、节点数和总响应，逐节点报告失败，不把部分结果标为完整。

不自动拆分、广播写操作；多 Key 能力仅在明确解析 Key 且满足路由约束时逐步开放。跨 Slot 等不支持场景先拒绝。

独立限制请求大小、响应字节、对象数量、嵌套、并发、频率和时间。超时/断线若无法证明未执行，记录结果未知，不自动重试。Redis 事务与 MySQL 不是同一事务；幂等执行认领持久化，崩溃后不自动重放未知写操作。相同幂等键不同参数拒绝，历史结果只回放安全摘要。

原始参数、Key/value、密码、脚本正文和完整响应不进入日志、审计、通用幂等快照或异步载荷。当前授权响应供页面显示，持久化只保存身份快照、目标、命令标识、策略版本、脱敏摘要、耗时、审批与结果状态。大批量修改交给可限速、暂停/恢复的治理任务。

## 分阶段交付

### 阶段一：定义与策略引擎

新增 ADR 明确 ADR-023 的扩展及授权边界；实现树、精确/通配匹配、继承、草稿审核、生效版本和最终策略计算。新增递增迁移，现有定义转换为显式策略，保持原启停与执行方式，不自动放宽。无法安全转换的定义禁用并给出迁移说明。更新 sql/latest 完整初始化包。

验收：默认拒绝、父禁用、精确拒绝不回退、参数选项绕过、通配授权、继承变更、移动节点、重复规则及并发版本更新测试。

### 阶段二：授权、执行与节点诊断

实现后端权限、共享写授权、确认/审批绑定、持久执行认领和结果未知状态；增加指定节点和受限多主诊断。迁移历史执行记录不伪造状态或参数内容。

验收：权限撤销、策略变化、授权过期、多实例竞争、重复点击、写后断线、数据库失败、超限响应、节点角色变化和多节点部分失败。

### 阶段三：命令管理与 CLI

实现树管理、影响预览、审核及 CLI 交互。预置主要数据结构和诊断命令，管理类默认禁用；更新操作文档。

验收：引号/转义/空参数、粘贴防误执行、补全与后端定义一致、权限可见状态、无持久敏感历史、桌面和小于 800px 窄屏。

### 阶段四：隔离集成与发布

在隔离 Redis 5.0.4 Standalone、Sentinel、Cluster 验证命令、认证和路由，不指向业务实例进行数据填充或删除。覆盖持久化和审计脱敏、增量升级及最新完整 SQL 回灌。Platform mvn verify、前端 npm ci/测试/build 通过，审查后按功能提交；发布和推送按用户授权执行。

所有阶段分别报告实际完成与剩余项。运行时版本支持判断不属于本计划；精确版本集成测试是交付验证，不会增加产品兼容矩阵。
