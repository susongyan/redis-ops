3. 应用关系：展示一个业务应用关联多个集群，区分资产关系与实际连接配置。
4. 同步任务：查看源/目标、任务状态和 Worker 归属；不启动或恢复任务。
5. Key 分布：介绍范围、规则、预算三步流程，再打开已有结果说明占比、规则快照及 CSV 导出。
6. 风险扫描及用户管理：介绍历史扫描和平台角色边界。
